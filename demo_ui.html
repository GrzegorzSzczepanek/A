About this tool

Hybrid pipeline that converts technical PDFs into DITA 1.3 XML. Deterministic parsing + XML serialization, with two LLM stages for topic planning and classification.

Validates output with DITA-OT 4.3.1 targeting HTML5 with --processing-mode=strict.

Default model: gemini-3.1-flash-lite · streaming SSE · context cache · thinking off

Per-PDF average wall-clock: ~25–30 s · cost: ~$0.005–0.015
